# Tom & Jerry Super Colorful Fun Calculator 🧀✨

[![Live Demo](https://img.shields.io/badge/demo-online-brightgreen.svg)](https://amal714.github.io/tom-and-jerry-calculator/)

An ultra-vivid, colorful web calculator designed to be delightful for kids, packed with juicy animations and Tom & Jerry cartoon elements!

🎮 **Play Live:** [https://amal714.github.io/tom-and-jerry-calculator/](https://amal714.github.io/tom-and-jerry-calculator/)

## Highlights

- **Tom & Jerry Interactive Background**:
  - Jerry the Mouse 🐭 and Tom the Cat 🐱 stickers with interactive click reactions and speech bubbles.
  - Floating cheese wedges 🧀, twinkling stars ⭐, balloons 🎈, and paw prints 🐾.
- **Candy Color Explosion**:
  - Over 16 distinct candy gradients across every button.
  - Shimmering animated holographic rainbow equals (`=`) button.
  - Playful 3D toy button press depth and jelly bounce effects.
- **Natural Expression Typing**:
  - Live typing on screen: everything you type appears directly on the display.
  - Results evaluate only when you press `Enter` or click the `=` button.
- **Party Theme Switcher**:
  - One-click toggle between **Candy Wonderland** and **Electric Party Rainbow** modes.
- **Keyboard Shortcuts**:
  - Numeric pad `0`–`9`, `.`, operators `+`, `-`, `*`, `/`, `Enter` (`=`), `Backspace` (`⌫`), `Escape` (`AC`), and `%`.

## How to Run

Open [index.html](index.html) in any web browser!
